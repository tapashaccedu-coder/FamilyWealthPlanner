# FamilyWealthPlanner

## Quick Start

### Run on your computer
Double-click **START.bat**
→ Opens at http://localhost:5173

### Publish to the internet (FREE)
Double-click **DEPLOY.bat**
→ Walks you through every step

---

## What you need (all free)

| Tool | Where to get it | Used for |
|------|----------------|---------|
| Node.js | nodejs.org (click LTS) | Running the app |
| Git | git-scm.com/download/win | Version control |
| GitHub account | github.com | Storing your code |
| Vercel account | vercel.com (sign in with GitHub) | Hosting the app |

---

## Transfer your financial plan between devices

Your plan is saved in **your browser only** — not in the app files.

To move it to another computer:
1. Open the app → top navigation bar → **Save / Load**
2. Click **Download settings file** → saves a `.json` file
3. On the other device → **Save / Load** → **Load settings file**

---

## Update the app (when you get a new version from Claude)

1. Unzip the new file into this same folder (replace files when asked)
2. Double-click **DEPLOY.bat** — it pushes the update automatically
3. Your URL stays exactly the same
